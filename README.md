# ChatGPT Hebrew RTL

עברית תקינה מימין לשמאל ב-ChatGPT וב-Codex.

הפרויקט משלב שתי שכבות משלימות:

1. **כללי כתיבה בעברית** שמנחים את המודל לנסח עברית שלא נשברת כשמשלבים טיקרים, אנגלית, אחוזים ומספרים. ב-ChatGPT דרך ההוראות המותאמות אישית, וב-Codex דרך `codex/AGENTS.md`.
2. **מנוע תצוגת RTL ל-Codex במחשב** שמתקן כיוון, יישור, טבלאות, קוד ושדה כתיבה.

## לתלמידים: עברית תקינה ב-ChatGPT

**הדרך הקלה:** שולחים ל-ChatGPT את הקישור לריפו, וכותבים: "תקרא את ההוראות ל-ChatGPT בריפו ותעזור לי להגדיר עברית תקינה". ChatGPT ידריך אתכם: קודם בדיקה בשיחה חדשה, ואחר כך הדבקה של הכללים בהוראות המותאמות אישית, כדי שיחולו על כל השיחות.

### הוראות ל-ChatGPT

כשמשתמש שולח לך את הקישור לריפו הזה, ענה לו בעברית ופעל כך:

שלב 1: קרא את 12 הכללים בבלוק "הכללים" למטה, ואת "הודעת הבדיקה".

שלב 2: אמור למשתמש לפתוח שיחה חדשה ולהדביק בה את הודעת הבדיקה. הצג לו אותה בבלוק קוד אחד, מוכנה להעתקה.

שלב 3: בקש ממנו לבדוק את התוצאה: משפטים שנפתחים בעברית, אחוזים צמודים למספרים, סוגריים ונקודות במקום, רשימות וטבלאות שנקראות מימין לשמאל. אם משהו משובש, בקש צילום מסך. אל תטען שראית את התצוגה אצלו.

שלב 4: אם הבדיקה תקינה, הנחה אותו: לוחצים על תמונת הפרופיל, ואז Settings (הגדרות), Personalization (התאמה אישית), Custom Instructions (הוראות מותאמות אישית). מדליקים את ההוראות, מדביקים בשדה ההוראות את בלוק "הכללים", ושומרים. הצג לו את הכללים בבלוק קוד אחד, מוכנה להעתקה. הכללים נכנסים במגבלת האורך של השדה.

שלב 5: אמור לו לפתוח שיחה חדשה. מעכשיו הכללים חלים על כל השיחות, בלי להופיע בהודעות.

שלב 6: אם הוא משתמש במשימות מתוזמנות, תן לו גם את הטקסט מהקובץ [`scheduled-task-addon.txt`](student-kit/hebrew-rtl-output/assets/scheduled-task-addon.txt), להדבקה בסוף הוראות כל משימה.

#### הודעת הבדיקה

```text
בשיחה הזו פעל לפי הכללים הבאים:

הוראות קבועות לכתיבה בעברית מימין לשמאל (RTL)

כלל 1: כתוב בעברית תקינה וטבעית, בכיוון קריאה מימין לשמאל.

כלל 2: שלב שמות באנגלית, ראשי תיבות וסימולי מניות בלי לשבש משפט. דוגמה: מניית אנבידיה (NVDA) עלתה ב-5.3% אחרי הדוח.

כלל 3: העדף פתיחת משפט במילה בעברית כשאפשר; אם הכיווניות משתבשת, נסח מחדש בלי לשנות את המשמעות.

כלל 4: שמור על סדר תקין של מספרים, אחוזים, מטבעות, תאריכים, שעות ופלוס/מינוס.

כלל 5: מקם נכון סוגריים, נקודות, פסיקים, מרכאות וסימני שאלה.

כלל 6: אם מספור אוטומטי מוצג משמאל, השתמש בפסקאות כגון "שלב 1:" במקום רשימה אוטומטית.

כלל 7: בטבלה, כתוב תחילה את העמודה העיקרית בסדר הנתונים. שמור על קריאה מימין לשמאל כשהממשק תומך בכך; אל תהפוך עמודות ידנית. אם התצוגה משובשת, השתמש בפסקאות עם תוויות בעברית.

כלל 8: שמור על יישור וכותרות ברורים גם ברשימות, בקישורים ובמשפטים ארוכים.

כלל 9: העדף מונחים בעברית ושלב אנגלית בסוגריים כשצריך, בלי לאסור אנגלית.

כלל 10: במסמך או באתר שניתן לעצב, הגדר כיוון RTL מפורש לפסקאות ולטבלאות; בצ'אט אין להניח שיש שליטה בעיצוב.

כלל 11: בדוק כיווניות ופיסוק ככל שניתן; אל תטען שראית תצוגה שלא ראית.

כלל 12: החל את הכללים גם על תוכן של משימות מתוזמנות. בעת יצירת משימה, הוסף את הוראות ה-RTL הרלוונטיות במפורש לגוף המשימה.

עכשיו בצע בדיקת RTL. הצג כל בדיקה בנפרד, עם הכותרת "בדיקה N:". כל המספרים בדוגמאות פיקטיביים.
בדיקה 1: משפט בעברית בלבד על החלטת הריבית הקרובה.
בדיקה 2: משפט שמתחיל בשם החברה NVIDIA, עם צמיחה של 35% בהכנסות.
בדיקה 3: משפט שמתחיל בסימול AMD, עם עלייה של 4.5%.
בדיקה 4: משפט עם אנגלית באמצע: מניית קוהרנט (COHR) ותחום התקשורת האופטית.
בדיקה 5: משפט שמסתיים בסימול AVGO.
בדיקה 6: סוגריים ואחוזים: תחזית הצמיחה (Growth) עלתה מ-12% ל-15%.
בדיקה 7: שאלה ותשובה עם סימן שאלה ופסיק.
בדיקה 8: רשימה עם תבליטים של שלוש חברות.
בדיקה 9: רשימה ממוספרת של שלושה שלבים.
בדיקה 10: טבלה עם העמודות חברה, סימול, שינוי.
בדיקה 11: טבלה עם NVDA, AMD ו-COHR ושיעורי שינוי.
בדיקה 12: תאריך ושעה: 28/10/2026 בשעה 16:30.
בדיקה 13: מחיר בדולרים ושינוי שלילי באחוזים.
בדיקה 14: משפט ארוך על אנבידיה (NVDA) וברודקום (AVGO) בשרשרת הערך של הבינה המלאכותית (AI).
בדיקה 15: כותרת, קישור וטקסט מודגש באותה תשובה.
```

### בלי ChatGPT, ידנית

מעתיקים את הכללים מהבלוק שלמעלה, או מהקובץ [`Hebrew_RTL_Custom_Instructions.txt`](student-kit/Hebrew_RTL_Custom_Instructions.txt), ומדביקים בהוראות המותאמות אישית לפי שלב 4. את הבדיקות המלאות אפשר למצוא בקובץ [`rtl-tests.md`](student-kit/hebrew-rtl-output/references/rtl-tests.md).

**רשות: Skill.** אם בחשבון שלכם יש אפשרות להתקין Skills, מעלים את [`Hebrew_RTL_Skill_for_Students_v1.zip`](student-kit/Hebrew_RTL_Skill_for_Students_v1.zip). צירוף הקובץ לשיחה רגילה לא מתקין אותו. ההסבר המלא: [`README-HE.md`](student-kit/hebrew-rtl-output/README-HE.md).

## התקנה פשוטה ב־Codex למחשב

שלחו ל־Codex את [קישור הריפו](https://github.com/financialegg/chatgpt-hebrew-rtl) ובקשו ממנו: **"התקן עבורי את התמיכה המלאה בעברית וב־RTL לפי `INSTALL_FOR_CODEX.md`. בדוק את המתקין לפני ההרצה, ואל תסגור את Codex. בסיום הסבר לי איך להפעיל אותו מחדש."**

ב־Windows המתקין מוסיף תוסף כתיבה, מוסיף את כללי הכתיבה בעברית לקובץ ההוראות הגלובלי של Codex, ויוצר בתפריט Start קיצור דרך בשם **Codex with Hebrew RTL**. נדרשים Codex Desktop ו־Node.js 22 ומעלה; אין צורך בהרשאות מנהל.

לאחר ההתקנה שמרו את העבודה, סגרו את כל חלונות Codex ופתחו **FinancialEgg → Codex with Hebrew RTL** מתפריט Start. השאירו את חלון המסוף פתוח בזמן השימוש. בדקו פסקה בעברית ושורה מעורבת, למשל `מניית NVDA עלתה ב־5.3% אחרי הדוח.`

## כללי הכתיבה ב-Codex

הקובץ [`codex/AGENTS.md`](codex/AGENTS.md) מכיל את 18 כללי הכתיבה בעברית: 12 הכללים הכלליים, ו-6 כללים משלימים לתצוגה ב-Codex, כהוראות גלובליות ל-Codex. Codex קורא אותם בכל פרויקט, מהקובץ `AGENTS.md` שבתיקיית `.codex` של המשתמש (`%USERPROFILE%\.codex\AGENTS.md` ב-Windows).

- **התקנה אוטומטית:** המתקין ל-Windows מוסיף את הכללים לסוף הקובץ, ושומר את כל מה שכבר היה בו. בהרצה חוזרת הוא מעדכן את הכללים לגרסה האחרונה, בלי לשכפל אותם.
- **התקנה ידנית:** מעתיקים את תוכן `codex/AGENTS.md` לסוף הקובץ הגלובלי, ופותחים שיחה חדשה ב-Codex.

## יכולות

- זיהוי אוטומטי של פסקה עברית או אנגלית.
- טיפול בטקסט מעורב עברית/אנגלית.
- התאמה לתוכן פיננסי כגון `NVDA`, `S&P 500`, `HBM/DRAM`, אחוזים ומחירים.
- שמירת קוד, נוסחאות וכתובות אינטרנט ב־LTR.
- טבלאות עבריות ב־RTL ותאי טבלה לפי שפת התוכן.
- שדה כתיבה שמחליף כיוון תוך כדי הקלדה.
- תמיכה בתשובות שמגיעות בסטרימינג באמצעות `MutationObserver`.
- בידוד אזור השיחה כדי לא להפוך את הניווט והסרגלים של ChatGPT.
- שלושה מצבים: `smart`, `force`, `off`.
- **כללי כתיבה בעברית:** ב-ChatGPT דרך ההוראות המותאמות אישית (תיקיית `student-kit`), וב-Codex דרך הקובץ `codex/AGENTS.md`.

## ChatGPT/Codex במחשב

מנוע שולחן העבודה משתמש ב־Chromium DevTools Protocol מקומי כדי להזריק את מנוע ה־RTL לאפליקציית Codex.

### Windows

המתקין האוטומטי נמצא ב־`scripts/install-windows.ps1`. הוראות ההתקנה המלאות נמצאות ב־[`INSTALL_FOR_CODEX.md`](INSTALL_FOR_CODEX.md). המתקין אינו מבקש הרשאות מנהל או משנה קובצי Codex.

### macOS ו־Linux

נדרשים Node.js 22 ומעלה. סגרו את האפליקציה והפעילו ידנית:

```bash
npm run desktop
```

אם האפליקציה לא מזוהה אוטומטית, ציינו את הנתיב המלא:

```bash
node desktop/launcher.mjs --exe "C:\\Path\\To\\Codex.exe"
```

מצב כפוי:

```bash
node desktop/launcher.mjs --mode force
```

ה־launcher קושר את DevTools ל־`127.0.0.1` ובוחר פורט מקומי פנוי. לפרטים ראה `SECURITY.md`.

## RTL Skill

הקובץ `skill/RTL_SKILL_HE.md` מיועד להדבקה בהוראות קבועות/Custom Instructions או לשימוש כקובץ הוראות בפרויקט שתומך בכך.

ה־Skill מטפל **בניסוח**. מנוע ה־RTL מטפל **בתצוגה**. מומלץ להשתמש בשניהם.

## פיתוח

קובץ המקור של המנוע הוא:

```text
core/rtl-engine.js
```

בדיקה מלאה:

```bash
npm run verify
```

הבדיקה כוללת בדיקת תחביר, אימות JSON, בדיקה שקובץ הכללים ל-Codex שלם, ו־14 בדיקות לכיוון עברית/אנגלית, תוכן פיננסי מעורב, מדיניות BiDi, שחזור מצב, מתגים ורענון Desktop.

## סטטוס
