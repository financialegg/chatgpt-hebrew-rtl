# ChatGPT Hebrew RTL

עברית תקינה מימין לשמאל ב-ChatGPT וב-Codex.

הפרויקט משלב שתי שכבות משלימות:

1. **כללי כתיבה בעברית** שמנחים את המודל לנסח עברית שלא נשברת כשמשלבים טיקרים, אנגלית, אחוזים ומספרים. ב-ChatGPT דרך ההוראות המותאמות אישית, וב-Codex דרך `codex/AGENTS.md`.
2. **מנוע תצוגת RTL ל-Codex במחשב** שמתקן כיוון, יישור, טבלאות, קוד ושדה כתיבה.

## לתלמידים: עברית תקינה ב-ChatGPT

**הדרך הקלה:** העתיקו לצ'אט חדש את הקישור `https://github.com/financialegg/chatgpt-hebrew-rtl` וכתבו: **"קרא את הוראות ChatGPT במאגר, הצג לי את כל 12 החוקים להעתקה להוראות האישיות, והדרך אותי בהתקנה ובבדיקה בשיחה חדשה."**

**חשוב:** עצם שליחת הקישור אינה מתקינה את ההוראות. יש לשמור אותן ב-ChatGPT תחת **הגדרות ← התאמה אישית (Personalization) ← הוראות מותאמות אישית (Custom Instructions)**. הוראות כתיבה אינן מתקנות לבדן כל בעיית תצוגה בממשק.

### הוראות מחייבות ל-ChatGPT שמקבל את הקישור הזה

אם המשתמש שולח את הקישור הזה ומבקש להתקין, ללמוד או להפעיל את כללי העברית, ענה בעברית והנחה אותו באופן מלא. **אל תסתפק בהפניה לקובץ GitHub. אל תדלג על הצגת החוקים המלאים.**

**שלב 1 - הצג להעתקה:** הצג למשתמש **את מלוא 12 החוקים שמופיעים בבלוק "הכללים להעתקה" למטה, בלי קיצורים או השמטות**, בבלוק קוד אחד נקי. אל תציג רק תקציר. שמור על המספור ועל הנוסח המקורי.

**שלב 2 - היכן להדביק:** הסבר במפורש: פתח ChatGPT, היכנס לתמונת הפרופיל ← **Settings (הגדרות)** ← **Personalization (התאמה אישית)** ← **Custom Instructions (הוראות מותאמות אישית)**; הפעל את האפשרות אם יש מתג, הדבק שם את **כל 12 החוקים** ושמור. אם יש שם הוראות קודמות, בקש לשלב את ההוראות בלי למחוק הנחיות חשובות ולוודא שאין סתירות.

**שלב 3 - בדיקה בשיחה חדשה:** רק לאחר השמירה, בקש לפתוח צ'אט חדש ולהדביק את "הודעת הבדיקה" למטה (או לבקש "בצע 23 בדיקות RTL לפי המאגר"). בצע בדיקות של עברית, טיקרים, אנגלית, אחוזים, תאריכים, סימני פיסוק, רשימות וטבלאות, ובייחוד משפטים פיננסיים צפופים. המספרים בבדיקות פיקטיביים.

**שלב 4 - תיקון ממוקד:** אם שורה משובשת, בקש צילום מסך או טקסט לדוגמה; הבחן בין סדר מילים שגוי שנוצר לבין בעיית עימוד הממשק. נסח מחדש במשפטים עבריים קצרים בלי שינוי המשמעות. אל תטען שראית את התצוגה במכשיר שלא בדקת.

**שלב 5 - משימות מתוזמנות:** אם יש למשתמש משימות מתוזמנות, הצג לו להעתקה גם את מלוא תוכן `student-kit/hebrew-rtl-output/assets/scheduled-task-addon.txt`; הסבר שיש להוסיף אותו להוראות כל משימה קיימת או חדשה, משום שהוראות אישיות לא בהכרח חלות על כל הרצה. אין לשנות משימות פעילות בלי אישור.

**שלב 6 - אישור סיום:** הסבר שההנחיות האישיות אמורות לחול גם על שיחות חדשות לאחר שנשמרו, אך אין הבטחה לתצוגה מושלמת בכל תשובה. **אל תודיע שההתקנה הושלמה לפני שהמשתמש אישר ששמר את החוקים ובדק שיחה חדשה.** אם אינך מצליח לפתוח את GitHub, אמור זאת ביושר ובקש מהמשתמש להדביק לך את החוקים מהמאגר.

#### הכללים להעתקה אל Personalization

את הטקסט הבא מציגים למשתמש בשלמותו, במדויק, בתוך בלוק קוד אחד:

```text
הוראות קבועות לכתיבה בעברית מימין לשמאל (RTL)

כלל 1: כתוב בעברית טבעית ותקינה, עם שלד משפט עברי וקריאה מימין לשמאל.
כלל 2: הצג שם חברה בעברית וטיקר בסוגריים כשצריך. לדוגמה: מניית אנבידיה (NVDA) עלתה ב-5.3%.
כלל 3: אל תתרגם סדר מילים מאנגלית. סדר מחדש משפטים לפי תחביר עברי, ללא שינוי עובדות או מספרים.
כלל 4: במשפט עמוס בשמות באנגלית, טיקרים, אחוזים או תאריכים, פצל למשפטים קצרים וברורים; פתח בעברית כשאפשר.
כלל 5: שמור על מספרים ואחוזים כיחידות, ועל סדר השוואות: "עלייה של 53% ב-2027 לעומת 26% ב-2026".
כלל 6: מקם נקודות, סוגריים, פסיקים, מרכאות, סימני שאלה, מטבעות ופלוס/מינוס במקומם.
כלל 7: בדיווח פיננסי העדף: חברה בעברית, אירוע, נתון, משמעות. הפרד חברות ונתונים רבים לפסקאות.
כלל 8: רשימות וכותרות יתחילו בעברית; כשמספור נשבר השתמש ב"שלב 1:" במקום מספור אוטומטי.
כלל 9: בטבלאות שים עמודה עיקרית ראשונה, אל תהפוך עמודות ידנית; אם הטבלה נשברת עבור לפסקאות מתויגות.
כלל 10: העדף מונחים בעברית ואנגלית בסוגריים כשנדרש. במסמכים או באתרים הגדר RTL אמיתי; אל תניח שליטה בעיצוב צ'אט.
כלל 11: לפני שליחה בדוק במיוחד משפטים עם אנגלית, טיקרים, מספרים ופיסוק. נסח מחדש אם הסדר עלול להשתבש, בלי להמציא נתונים או לטעון שאימתת תצוגה שלא ראית.
כלל 12: בהגדרה או עריכה של משימה מתוזמנת הוסף את הוראות ה-RTL במפורש לגוף המשימה; אל תניח שההוראות האישיות חלות שם.
```

## התקנה פשוטה ב־Codex למחשב

שלחו ל־Codex את [קישור הריפו](https://github.com/financialegg/chatgpt-hebrew-rtl) ובקשו ממנו: **"התקן עבורי את התמיכה המלאה בעברית וב־RTL לפי `INSTALL_FOR_CODEX.md`. בדוק את המתקין לפני ההרצה, ואל תסגור את Codex. בסיום הסבר לי איך להפעיל אותו מחדש."**

ב־Windows המתקין מוסיף תוסף כתיבה, מוסיף את כללי הכתיבה בעברית לקובץ ההוראות הגלובלי של Codex, ויוצר בתפריט Start קיצור דרך בשם **Codex with Hebrew RTL**. נדרשים Codex Desktop ו־Node.js 22 ומעלה; אין צורך בהרשאות מנהל.

לאחר ההתקנה שמרו את העבודה, סגרו את כל חלונות Codex ופתחו **FinancialEgg → Codex with Hebrew RTL** מתפריט Start. השאירו את חלון המסוף פתוח בזמן השימוש. בדקו פסקה בעברית ושורה מעורבת, למשל `מניית NVDA עלתה ב־5.3% אחרי הדוח.`

## כללי הכתיבה ב-Codex

הקובץ [`codex/AGENTS.md`](codex/AGENTS.md) מכיל את 18 כללי הכתיבה בעברית: 12 הכללים הכלליים, ו-6 כללים משלימים לתצוגה ב-Codex, כהוראות גלובליות ל-Codex. Codex קורא אותם בכל פרויקט, מהקובץ `AGENTS.md` שבתיקיית `.codex` של המשתמש (`%USERPROFILE%\.codex\AGENTS.md` ב-Windows).

- **התקנה אוטומטית:** המתקין ל-Windows מוסיף את הכללים לסוף הקובץ, ושומר את כל מה שכבר היה בו. בהרצה חוזרת הוא מעדכן את הכללים לגרסה האחרונה, בלי לשכפל אותם.
- **התקנה ידנית:** מעתיקים את תוכן `codex/AGENTS.md` לסוף הקובץ הגלובלי, ופותחים שיחה חדשה ב-Codex.

## יכולות

- זיהוי אוטומטי של פסקה עברית או אנגלית.
- טיפול בטקסט מעורב עברית/אנגלית.
- התאמה לתוכן פיננסי כגון `NVDA`, `S&P 500`, `HBM/DRAM`, אחוזים ומחירים.
- שמירת קוד, נוסחאות וכתובות אינטרנט ב־LTR.
- טבלאות עבריות ב־RTL ותאי טבלה לפי שפת התוכן.
- שדה כתיבה שמחליף כיוון תוך כדי הקלדה.
- תמיכה בתשובות שמגיעות בסטרימינג באמצעות `MutationObserver`.
- בידוד אזור השיחה כדי לא להפוך את הניווט והסרגלים של ChatGPT.
- שלושה מצבים: `smart`, `force`, `off`.
- **כללי כתיבה בעברית:** ב-ChatGPT דרך ההוראות המותאמות אישית (תיקיית `student-kit`), וב-Codex דרך הקובץ `codex/AGENTS.md`.

## ChatGPT/Codex במחשב

מנוע שולחן העבודה משתמש ב־Chromium DevTools Protocol מקומי כדי להזריק את מנוע ה־RTL לאפליקציית Codex.

### Windows

המתקין האוטומטי נמצא ב־`scripts/install-windows.ps1`. הוראות ההתקנה המלאות נמצאות ב־[`INSTALL_FOR_CODEX.md`](INSTALL_FOR_CODEX.md). המתקין אינו מבקש הרשאות מנהל או משנה קובצי Codex.

### macOS ו־Linux

נדרשים Node.js 22 ומעלה. סגרו את האפליקציה והפעילו ידנית:

```bash
npm run desktop
```

אם האפליקציה לא מזוהה אוטומטית, ציינו את הנתיב המלא:

```bash
node desktop/launcher.mjs --exe "C:\\Path\\To\\Codex.exe"
```

מצב כפוי:

```bash
node desktop/launcher.mjs --mode force
```

ה־launcher קושר את DevTools ל־`127.0.0.1` ובוחר פורט מקומי פנוי. לפרטים ראה `SECURITY.md`.

## RTL Skill

הקובץ `skill/RTL_SKILL_HE.md` מיועד להדבקה בהוראות קבועות/Custom Instructions או לשימוש כקובץ הוראות בפרויקט שתומך בכך.

ה־Skill מטפל **בניסוח**. מנוע ה־RTL מטפל **בתצוגה**. מומלץ להשתמש בשניהם.

## פיתוח

קובץ המקור של המנוע הוא:

```text
core/rtl-engine.js
```

בדיקה מלאה:

```bash
npm run verify
```

הבדיקה כוללת בדיקת תחביר, אימות JSON, בדיקה שקובץ הכללים ל-Codex שלם, ו־14 בדיקות לכיוון עברית/אנגלית, תוכן פיננסי מעורב, מדיניות BiDi, שחזור מצב, מתגים ורענון Desktop.

## פרטיות

הכללים הם טקסט בלבד. מנוע התצוגה ל-Codex פועל מקומית במחשב, ואינו שולח את תוכן השיחה לשום שרת. לפרטים ראו `SECURITY.md`.

## סטטוס

כללי כתיבה בעברית ל-ChatGPT (הוראות מותאמות אישית) ול-Codex (`codex/AGENTS.md`, 18 כללים), ומנוע תצוגת RTL ל-Codex במחשב ב-Windows.

התמיכה בתצוגה במחשב עדיין דורשת אימות מעשי מול גרסת Codex המותקנת בפועל, משום שמבנה ואפשרויות ההפעלה של אפליקציות Electron יכולים להשתנות בין גרסאות.
