# ערכת כתיבה בעברית תקינה (RTL) לתלמידים

ערכת הוראות ליצירת טקסט עברי קריא עם אנגלית, מספרים, טבלאות ורשימות. גרסה 1.1, 08/10/2026.

## הדרך המומלצת לכל תלמיד: הוראות אישיות

שלב 1: פתחו את ChatGPT > הגדרות > התאמה אישית > הוראות מותאמות אישית.

שלב 2: הפעילו את ההוראות האישיות והדביקו את כל הטקסט מקובץ `assets/custom-instructions.txt` (או מקובץ ה-TXT הנפרד שהופץ לכם).

שלב 3: שמרו את ההגדרות, פתחו שיחה חדשה והריצו בדיקה. קובץ `references/rtl-tests.md` כולל 15 בדיקות מייצגות.

שלב 4: ודאו שמספור, תבליטים, כותרות וטבלאות אכן מוצגים נכון במכשיר שלכם. אם משהו לא תקין, צלמו את המסך. ניסוח נכון אינו מבטיח אוטומטית יישור נכון בכל ממשק.

## מסלול Skill, אם האפשרות נתמכת בחשבון

שלב 1: מצאו את מסך ניהול ה-Skills בסביבת העבודה הרלוונטית.

שלב 2: העלו את חבילת ה-ZIP על פי אפשרויות ההתקנה המוצגות במוצר.

שלב 3: ודאו שה-Skill הופעל והריצו את הבדיקות.

חשוב: צירוף ZIP לשיחה רגילה *לא* מתקין Skill אוטומטית לכל השיחות. אם אין אפשרות התקנת Skills בחשבון, השתמשו בהוראות האישיות.

## משימות מתוזמנות

הדביקו את `assets/scheduled-task-addon.txt` בסוף הגדרת *כל משימה* שאתם מעוניינים שתכתוב בעברית תקינה. הוראות אישיות או Skill אינם מבטיחים שהתוכן יהיה מוצג נכון בכל סוג התראה. יש לבדוק בפועל הרצה מתוזמנת.
